# 🏆 Golden Deploy — Золотая связка

Это выжимка из лаборатории. Здесь **только то, что реально работает** с винрейтом 81.8% и PnL +$5.86.

## Что здесь:
- `okx_mutator.py` — пул стратегий.
- `okx_grid.py` — логика сетки (нужна для импорта).
- `okx_bot_prod.py` — чистый бот (переименован из v2, без тестового мусора).
- `golden_config.json` — **самый важный файл**. Здесь прописаны только XRP, ETH и рабочие TP/SL.

## Как перенести на боевой сервер (VPS):
1. Установи Python 3.10+, `pip install numpy urllib3`.
2. Закинь эти 4 файла в папку `/root/trading_bot/`.
3. В `okx_bot_prod.py` замени `paper_trade = True` на `False` (и добавь реальные API-ключи OKX).
4. Запусти: `python3 okx_bot_prod.py`.

## Почему именно XRP и ETH?
- **XRP**: 13 сделок, 100% побед.
- **ETH**: 4 сделки, 75% побед.
- **SOL**: 0 побед (убран из конфига).
- **BTC/DOGE**: не прошли бэктест на 30 дней.
